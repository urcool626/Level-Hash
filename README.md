# Level Hash
Level Hash is a mod that can generate a fingerprint for Geometry Dash levels to help detect cheating such as Level Edit.

Disclaimer: AI was used to help make this project possible.

[I Made a Mod to Detect CHEATERS in Geometry Dash!](https://www.youtube.com/watch?v=nmsVMrcseTk)

<img src="logo.png" width="150" alt="the mod's logo" />

## Features
- SHA-256 Hash Generation for levels
- Automatic matching of hash and Level ID.

## Build

To build this mod, make sure you have the Geode SDK and CLI and also all dependencies installed.
The necessary instructions for installing them are available at https://docs.geode-sdk.org/getting-started/prerequisites

1. Clone the github repo.
   
    ``git clone https://github.com/urcool626/Level-Hash/``
   
    ``cd Level-Hash/``

2. Build the project

    ``geode build``

## Dependencies
This mod requires [GDShare](https://github.com/HJfod/GDShare)

## Installation

To install this mod follow the instructions below.
If you built the mod yourself, it should automatically be installed and you can skip the installation process.

1. [Download the latest release](https://github.com/urcool626/Level-Hash/releases)

2. Move the downloaded file to

    ``Geometry Dash/geode/mods/``
